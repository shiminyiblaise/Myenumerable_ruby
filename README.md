# 📖MyEnumerable <a name="about-project"></a>
This project implements a custom list class (MyList) and a module (MyEnumerable) that mimics a subset of Ruby's Enumerable functionality. The MyEnumerable module provides three methods: #all?, #any?, and #filter, allowing for collection traversal and manipulation.

*[MyEnumerable]* is a ruby project which helps you understands ruby Enumerable functionality.

## 🛠 Built With <a name="built-with"></a>

### Tech Stack <a name="tech-stack"></a>

-Ruby: The primary programming language use

Bundler: A Ruby dependency manager used to manage gem dependencies specified in the Gemfile.

IRB (Interactive Ruby): A REPL (Read-Eval-Print Loop) used for testing the functionality 

### Key Features <a name="key-features"></a>
Initializes with a list of items.
Implements the #each method to iterate over the list.
Implements #all?: Checks if all elements meet a given condition.
Implements #any?: Checks if any element meets a given condition.
Implements #filter: Returns a new array containing elements that meet a given condition.
